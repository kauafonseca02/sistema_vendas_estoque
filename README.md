# Sistema de Vendas e Estoque

Projeto desenvolvido em Python para praticar lógica de programação, organização de código em funções e manipulação de dados.

## Funcionalidades

- Cadastro de produtos.
- Validação de nomes, preços e quantidades.
- Prevenção de produtos duplicados.
- Listagem dos produtos cadastrados.
- Registro de vendas com validação de estoque.
- Atualização automática do estoque após uma venda.
- Histórico de vendas.
- Cálculo do faturamento total.
- Salvamento e carregamento de dados utilizando JSON.
- Tratamento de erros de entrada e leitura do arquivo JSON.
    
## Tecnologias utilizadas

- Python
- JSON
- Git e GitHub

## Como executar

1. Instale o Python.    
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```

Os dados são armazenados localmente no arquivo `dados.json`, criado pelo sistema.

## Objetivo

Projeto de estudos desenvolvido para consolidar conhecimentos em Python e construir experiência prática com desenvolvimento de software.

## Aprendizados

Durante o desenvolvimento, pratiquei funções, listas, dicionários, estruturas condicionais, laços de repetição, tratamento de exceções, persistência de dados e versionamento com Git.
